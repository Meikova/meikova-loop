      Cài MashLoop trên Mobile

      Địa chỉ truy cập: http://100.118.230.52:8765

      Quét Camera iPhone / Androidđể mở ứng dụng tức thì trên điện thoại.

      http://100.118.230.52:8765 ↗

      iOS (iPhone)

      1. Mở Safari trên iPhone, truy cập địa chỉ máy chủ hoặc quét mã QR.
      2. Bấm nút Chia sẻ (biểu tượng mũi tên hướng lên) ở thanh dưới Safari.
      3. Chọn Thêm vào MH chính (Add to Home Screen).
      4. Ứng dụng chạy toàn màn hình, hỗ trợ Dynamic Island và phát nền khi khoá máy.

      Mã nguồn Xcode native tại: ios/App

      Android

      1. Mở Chrome trên điện thoại, truy cập link web hoặc quét mã QR.
      2. Bấm menu ⋮ góc trên → chọn Cài đặt ứng dụng (Install App).
      3. Hoặc build file APK từ thư mục Android Studio: android/

      Quyền chạy nền WAKE_LOCK & FOREGROUND_SERVICE đã được bật sẵn.

      Phím tắt & Hướng dẫn

      Điều khiển phát nhạc

      Space
      Phát hoặc tạm dừng
      J
      Nhảy phách trong bài (Jump)
      N
      Chuyển bài khác ở điểm nối gần nhất
      K
      Sang kho bài khác
      L
      Khoá lặp bài này mãi (Loop Lock)
