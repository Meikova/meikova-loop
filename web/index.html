      02
      Tự động tích hợp Media Control của OS

      Hỗ trợ Windows SMTC overlay, macOS Control Center widget & Linux MPRIS2 D-Bus.

      Native 64-bit · Audio Engine độc lập · Không giới hạn thời lượng bài
      01
      Mở Safari hoặc quét mã QR

      Bấm nút Chia sẻ (mũi tên hướng lên) ở thanh dưới cùng của Safari.

      02
      Thêm vào MH chính (PWA) hoặc cài đặt .IPA

      Chọn Thêm vào MH chính để dùng như app gốc, hoặc nạp file .IPA qua AltStore / Sideloadly.

      Phát nền khi khóa màn hình · Dynamic Island · Control Center
      01
      Tải file APK trực tiếp hoặc cài đặt PWA

      Bấm tải .APK ở trên và mở file để Cài đặt, hoặc mở Chrome bấm menu ⋮ → Cài đặt ứng dụng.

      02
      Chạy ứng dụng toàn màn hình độc lập
